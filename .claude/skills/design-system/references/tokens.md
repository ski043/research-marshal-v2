# Design tokens

Every colour is written as `oklch()` in `app/globals.css`, once for `:root` (light) and once for `.dark`. The hex value is the same colour in sRGB. A Tailwind utility takes the token name without the dashes: `--primary-ink` is `text-primary-ink`, `bg-primary-ink`, `border-primary-ink`.

## Motion

| Class | Value | Use |
| --- | --- | --- |
| `duration-100` | 100ms | A popover that opens or closes. |
| `duration-150` | 150ms | A change under the pointer: colour, fill, border, the press of a chip. |
| `duration-200` | 200ms | Something that moves or arrives: a new Activity row, an open row, the width of the sidebar. |
| `duration-300` | 300ms | A screen that enters: the greeting, a notice, one cell of a dithered glyph. |
| `duration-400` | 400ms | The slowest step: the suggestion chips, one after the other, 30ms apart, and a dot of the waiting bridge as it lights. |

| Class | Value | Use |
| --- | --- | --- |
| `ease-out` |  | The default. Motion starts at once and settles. |
| `ease-[cubic-bezier(0.23,1,0.32,1)]` | cubic-bezier(0.23, 1, 0.32, 1) | A longer way in that needs a soft landing: the suggestion chips, the rotating placeholder. |

The one long loop is the placeholder of the prompt box: `placeholder 2.8s cubic-bezier(0.23, 1, 0.32, 1) both`.
